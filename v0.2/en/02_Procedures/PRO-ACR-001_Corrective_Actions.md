## 1. Purpose

Define the rules for root cause analysis, implementation, and effectiveness verification of corrective actions in order to eliminate the causes of nonconformities and prevent their recurrence within the QMS of Plus Sarl.

## 2. Scope

Any nonconformity requiring a corrective action:
- Major NCs (systematically)
- Recurrent minor NCs
- Internal or external audit NCs
- Significant or repetitive customer complaints
- Any situation where the managing director deems it necessary to act on the causes

## 3. Definitions

| Term | Definition |
|---|---|
| **Correction** | Action to eliminate a detected NC (immediate treatment of the symptom) |
| **Corrective action** | Action to eliminate the **cause** of a NC and prevent its recurrence |
| **Root cause** | The fundamental cause at the origin of the NC |
| **Effectiveness verification** | Check that the corrective action has indeed prevented the recurrence of the NC |

> **Key difference:**
> - Correction = "I replaced the defective parts for the customer" (symptom)
> - Corrective action = "I asked the factory to implement enhanced inspection on this reference" (cause)

### 5.2 Step Details

**Step 1 - Open the CA Form**

- Assign a number: AC_[YYYY]_[NNN]
- Link to the originating NC (NC_[YYYY]_[NNNN])
- Describe the problem

**Step 2 - Analyze the Causes**

The cause analysis is carried out by the managing director within the scope of her competence, in coordination with the Chinese partners when the NC is related to manufacturing.

Use the 5 Whys method (recommended for Plus Sarl):

| # | Why? | Answer |
|---|---|---|
| 1 | Why did the NC occur? | [Answer 1] |
| 2 | Why [Answer 1]? | [Answer 2] |
| 3 | Why [Answer 2]? | [Answer 3] |
| 4 | Why [Answer 3]? | [Answer 4] |
| 5 | Why [Answer 4]? | [Answer 5 = probable root cause] |

### 5.3 Typical Corrective Actions for Plus Sarl

The objective of corrective actions is to prevent the recurrence of NCs and to reduce the impact on customers. Below are the most frequent scenarios and associated corrective actions:

#### Scenario 1: Transport Delay

| Element | Detail |
|---|---|
| **Problem** | Delivery delay related to the carrier or freight forwarder |
| **Typical root cause** | Unreliable carrier/freight forwarder, logistics issues |
| **Corrective actions** | - Re-evaluate the concerned carrier/freight forwarder |
| | - Inform Chinese partners to avoid this provider in the future |
| | - Adapt the logistics choice (mode change: air/sea/rail) |
| | - Anticipate timelines in customer communications |

#### Scenario 2: Production Delay

| Element | Detail |
|---|---|
| **Problem** | Manufacturing delay at the Chinese partner |
| **Typical root cause** | Insufficient planning, factory overload, technical issue |
| **Corrective actions** | - Enhanced monitoring with Chinese partners (more frequent progress updates) |
| | - Push for better timelines and improved planning |
| | - Anticipate communications to customers in case of delay risk |
| | - Commercial adjustments if necessary (goodwill gesture, staggered delivery) |

#### Scenario 3: Production Defect

| Element | Detail |
|---|---|
| **Problem** | Parts not conforming to specifications (dimensions, appearance, material) |
| **Typical root cause** | Machine adjustment issue, mould wear, material error, insufficient inspection |
| **Corrective actions** | - Request the factory to retain the NC information |
| | - Request the implementation of enhanced inspections on future production runs of this reference |
| | - Replacement of nonconforming parts for the customer |
| | - Logistics adaptation if necessary (urgent re-shipment) |
| | - Enhanced partner monitoring (continuous quality monitoring) |
| | - Commercial adjustments if necessary |

#### Scenario 4: Labelling or Packaging Error

| Element | Detail |
|---|---|
| **Problem** | Labelling or packaging error (incorrect reference on label, mix-up between similar references) |
| **Typical root cause** | Mix-up between similar references, absence of inspection checklist, insufficient verification before shipment |
| **Corrective actions** | - Create a comprehensive quality control checklist covering labelling and packaging |
| | - Strengthen label verification before shipment |
| | - Clarify references with the supplier (particularly similar references that may cause confusion) |
| | - Request the supplier to implement a double-check on labelling |

> **Guiding principle:** The corrective actions of Plus Sarl aim to prevent recurrence and reduce the impact on the customer. The managing director acts within the scope of her competence and relies on her Chinese partners for the technical aspects of manufacturing.

**Step 3 - Identify the Root Cause**

- Select the most probable cause
- Verify with data/evidence if possible (photos, reports, email/WeChat exchanges)

**Step 4 - Define the Corrective Action**

The corrective action must:
- Act on the root cause (not on the symptom)
- Be realistic and proportionate to the means of Plus Sarl
- Have a responsible person and a deadline
- Be communicated to the relevant Chinese partner if necessary

**Step 5 - Implement**

- Carry out the action or coordinate its implementation by the Chinese partner
- Document what was done
- Communicate the actions to the concerned parties (Chinese partner, customer, carrier)

**Step 6 - Verify Effectiveness**

- Wait a sufficient period (generally 1 to 3 months or the next orders of the same type)
- Verify that the NC has not recurred during subsequent production runs/deliveries
- If the NC recurs: resume the cause analysis, consider stronger measures
