# Projet de Certification ISO 9001:2015 - DUMMY Sarl

## Objectif

Ce depot contient l'ensemble des documents necessaires a la mise en place d'un Systeme de Management de la Qualite (SMQ) conforme a la norme ISO 9001:2015 pour **DUMMY Sarl**.

## Profil de l'entreprise

| Element | Detail |
|---|---|
| Raison sociale | DUMMY Sarl |
| Pays | Suisse |
| Effectif | 1 salariee (gerante) |
| Actionnaires | 3 (dont la gerante) |
| Locaux | 1 bureau |
| Activite | Developpement de moules pour injection plastique et livraison |
| Fabrication | Externalisee en Chine (partenaire) |
| Clients | Suisses et europeens (B2B) |
| Motivation | Exigence client de certification fournisseurs |

## Comment utiliser ce depot

1. **Lire le guide** : Commencez par `GUIDE_CERTIFICATION.md`
2. **Suivre le planning** : Respectez les etapes dans `PLANNING.md`
3. **Remplir les modeles** : Completez chaque document dans `modeles/`
4. **Remplacer les `[...]`** : Chaque champ entre crochets est a personnaliser
5. **Conserver les versions** : Utilisez git pour tracer les evolutions
