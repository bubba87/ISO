## 1. Purpose

This work instruction describes the procedure for conducting a **During Production Check (DUPRO)** at the supplier's facility when production has reached approximately 30–50% completion. The DUPRO monitors in-process quality, detects deviations early, and enables timely corrective measures.

---

## 2. Scope

This instruction applies to all orders requiring a DUPRO inspection as defined in the inspection plan (A1 of process P03).

---

## 3. Trigger Criteria

| Criterion                            | Description                                          |
|--------------------------------------|------------------------------------------------------|
| Standard order                       | DUPRO at 30-50% production completion                |
| High-value or high-volume order      | Mandatory DUPRO                                      |
| Supplier under enhanced surveillance | Mandatory DUPRO                                      |
| Previous IPC with conditional pass   | Mandatory DUPRO to verify corrective actions         |

---

## 4. Preparation

| Step | Action                                   | Responsible   | Documents                     |
|------|------------------------------------------|---------------|-------------------------------|
| 1    | Confirm production status (30-50%)       | Quality Role  | Supplier production schedule  |
| 2    | Review IPC results if applicable         | Quality Role  | FM-P03-IPC report             |
| 3    | Prepare DUPRO checklist                  | Quality Role  | FM-P03-DUPRO template         |
| 4    | Prepare sampling plan (AQL if applicable)| Quality Role  | IT-P03-ECH                    |
| 5    | Confirm inspection date with supplier    | Quality Role  | Communication record          |

---

## 5. Inspection Procedure

### 5.1 Production Progress Verification

| Check Point                          | Method                                               | Acceptance Criteria              |
|--------------------------------------|------------------------------------------------------|----------------------------------|
| Production quantity completed        | Count / production records                           | 30-50% of total order           |
| Production schedule adherence        | Review of schedule vs. actual progress               | On track for delivery date       |
| Raw material consumption             | Visual check / records                               | Consistent with plan            |

### 5.2 In-Process Quality Verification

| Check Point                          | Method                                               | Acceptance Criteria              |
|--------------------------------------|------------------------------------------------------|----------------------------------|
| Dimensional conformity               | Sampling measurement per AQL plan                    | Within drawing tolerances        |
| Visual appearance                    | Visual inspection per reference sample               | No visible defects               |
| Functional requirements              | Functional test (if applicable)                      | Meet specification               |
| Workmanship quality                  | Visual inspection                                    | Consistent, clean finish         |

### 5.3 Process Control Verification

| Check Point                          | Method                                               | Acceptance Criteria              |
|--------------------------------------|------------------------------------------------------|----------------------------------|
| Production parameters maintained     | Review of settings / records                         | Match with process sheet         |
| In-process quality records           | Document review                                      | Being maintained                 |
| NC products segregation              | Visual check                                         | Properly identified / isolated   |
| Corrective actions from IPC          | Verification of implementation                       | Effectively implemented          |

### 5.4 Packaging Verification (if started)

| Check Point                          | Method                                               | Acceptance Criteria              |
|--------------------------------------|------------------------------------------------------|----------------------------------|
| Packaging materials                  | Visual inspection                                    | Per packing specification        |
| Marking / labeling (samples)         | Visual verification                                  | Correct and complete             |
| Packing method                       | Visual check                                         | Adequate product protection      |

---

## 6. Decision

| Result          | Action                                               |
|-----------------|------------------------------------------------------|
| **PASS**        | Production may continue. Record on FM-P03-DUPRO.     |
| **CONDITIONAL** | Deviations noted. Corrective actions defined. Follow-up or additional DUPRO scheduled. |
| **FAIL**        | Production halted. NC report opened (FM-P03-NC). Corrective action required before resumption. |
