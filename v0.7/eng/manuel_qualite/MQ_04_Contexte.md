## 4.1 Understanding the Organization and Its Context

Plus Sarl operates in the industrial monitoring and worldwide sourcing sector. Understanding the internal and external context is essential to guide the Quality Management System.

### 4.1.1 External Issues

| Category           | Identified Issues                                                              |
|--------------------|--------------------------------------------------------------------------------|
| Economic           | Exchange rate fluctuations, international transport cost changes               |
| Regulatory         | Compliance with international standards, multiple customs regulations          |
| Technological      | Digitalization of trade, remote monitoring tools, online platforms             |
| Competitive        | Presence of international competitors, price pressure                          |
| Geopolitical       | Instability in certain regions, international trade barriers                   |
| Environmental      | Growing requirements for sustainability and social responsibility             |

### 4.1.2 Internal Issues

| Category           | Identified Issues                                                              |
|--------------------|--------------------------------------------------------------------------------|
| Organizational     | Agile human-scale structure, need for role versatility                         |
| Competencies       | Technical expertise in sourcing and quality, foreign language proficiency      |
| Processes          | QMS maturity, standardization of working methods                               |
| Infrastructure     | IT tools, communication resources, document management system                  |
| Culture            | Customer orientation, quality commitment, continual improvement               |

## 4.2 SWOT Analysis

| Dimension         | Elements                                                                                          |
|-------------------|----------------------------------------------------------------------------------------------------|
| **Strengths (S)** | - Recognized expertise in international industrial monitoring                                      |
|                   | - Network of qualified suppliers worldwide                                                         |
|                   | - Agile structure enabling high responsiveness                                                     |
|                   | - In-depth knowledge of international quality standards                                            |
|                   | - Ability to operate on all continents                                                             |
| **Weaknesses (W)**| - Dependency on external service providers for inspections                                         |
|                   | - Small size limiting simultaneous processing capacity                                             |
|                   | - Need to strengthen process documentation                                                         |
|                   | - Information system to be consolidated                                                            |
| **Opportunities (O)**| - Growing demand for qualified international sourcing services                                  |
|                   | - Development of new geographic markets                                                            |
|                   | - Digitalization of inspection and monitoring services                                             |
|                   | - Strategic partnerships with local inspection bodies                                              |
|                   | - ISO 9001 certification as a competitive advantage                                                |
| **Threats (T)**   | - Increased competition in the international sourcing market                                       |
|                   | - Logistics risks related to international transport                                               |
|                   | - Rapid evolution of regulatory requirements in different countries                                 |
|                   | - Currency risks and regional economic instability                                                 |

## 4.3 Relevant Interested Parties

### 4.3.1 Identification of Interested Parties

| Interested Party           | Needs and Expectations                                                   | Level of Influence |
|---------------------------|--------------------------------------------------------------------------|---------------------|
| Customers                 | Product quality, on-time delivery, transparency, traceability            | High                |
| International suppliers   | Fair relationships, clear specifications, order continuity               | High                |
| Employees (all roles)     | Working conditions, training, recognition, stability                     | High                |
| Inspection bodies         | Precise specifications, adequate planning                                | Medium              |
| Regulatory authorities    | Legal compliance, compliant declarations                                 | Medium              |
| Freight forwarders / logistics providers | Clear instructions, complete documentation                  | Medium              |
| Financial partners        | Business sustainability, solvency                                        | Medium              |
| Competitors               | Fair market practices                                                    | Low                 |

### 4.3.2 Monitoring of Interested Parties

| Interested Party           | Monitoring Method                      | Frequency          | Responsible       |
|---------------------------|----------------------------------------|--------------------|-------------------|
| Customers                 | Satisfaction surveys, complaints       | Continuous         | Commercial Role   |
| Suppliers                 | Periodic evaluations, audits           | Semi-annual        | Purchasing Role   |
| Employees                 | Individual interviews, reviews         | Annual             | Management        |
| Regulatory authorities    | Regulatory watch                       | Continuous         | Quality Role      |

## 4.4 Scope of the QMS

### 4.4.1 Perimeter

The Quality Management System of Plus Sarl applies to all activities related to **industrial monitoring and worldwide sourcing**, including:

- Sales management and customer relations
- Selection and qualification of international suppliers
- Production monitoring and quality inspections
- International logistics coordination
- QMS document management

### 4.4.2 Exclusions

| ISO 9001:2015 Clause | Excluded Requirement                         | Justification                                                 |
|-----------------------|----------------------------------------------|---------------------------------------------------------------|
| 8.3                   | Design and development                        | Plus Sarl does not design products; design is performed by customers or suppliers |

### 4.4.3 Sites Covered

The QMS covers all operations of Plus Sarl, regardless of the geographic location of interventions. Inspections and audits are performed at supplier sites worldwide.

## 4.5 Quality Management System and Its Processes

### 4.5.1 Process Approach

Plus Sarl applies a process approach in accordance with the requirements of the ISO 9001:2015 standard. Processes are defined, documented and monitored using performance indicators.

### 4.5.2 Identified Processes

| Type           | Code  | Process                          | Main Inputs                            | Main Outputs                           |
|----------------|-------|----------------------------------|----------------------------------------|----------------------------------------|
| Management     | PM01  | Strategic management             | Context, interested party requirements | Policy, objectives, resources          |
| Realization    | P01   | Sales management                 | Customer request                       | Validated order                        |
| Realization    | P02   | Purchasing and sourcing          | Specifications                         | Selected supplier, order               |
| Realization    | P03   | Monitoring and quality control   | Supplier order                         | Inspection report, decision            |
| Realization    | P04   | Logistics and shipping           | Released product                       | Customer delivery                      |
| Support        | PS01  | Document management              | Documentation needs                    | Controlled documents                   |
| Support        | PS02  | Competence management            | Competency needs                       | Competent personnel                    |
| Support        | PS03  | Continual improvement            | NCs, audits, customer feedback         | Corrective actions, improvement plans  |

### 4.5.3 Risks and Opportunities by Process

The risks and opportunities associated with each process are identified and addressed in Chapter 6 of this Quality Manual (MQ_06_Planification).
