### 3.2 Classification A/B/C

| Classification | Score          | Description                                              | Action                          |
|---------------|----------------|----------------------------------------------------------|---------------------------------|
| **A - Excellent** | >= 80/100  | Fournisseur stratégique, performance excellente          | Maintenir, développer le partenariat |
| **B - Acceptable** | 60-79/100 | Performance satisfaisante, axes d'amélioration identifiés | Plan d'amélioration, suivi renforcé |
| **C - Insuffisant** | < 60/100 | Performance insuffisante, risques identifiés             | Plan d'action urgent, envisager remplacement |
