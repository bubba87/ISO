## 1. Purpose

This work instruction describes the procedure for conducting a **Loading Check** at the supplier's facility or at the loading point (port, warehouse). The Loading Check verifies the packaging, labeling, quantity, container condition, and loading arrangement before the container is sealed for shipment.

---

## 2. Scope

This instruction applies to all shipments requiring a Loading Check as defined in the inspection plan (A1 of process P03).

---

## 3. Trigger Criteria

| Criterion                            | Description                                          |
|--------------------------------------|------------------------------------------------------|
| Standard container shipment          | Loading Check recommended                            |
| High-value shipment                  | Mandatory Loading Check                              |
| Fragile or hazardous goods           | Mandatory Loading Check                              |
| Supplier with previous logistics NC  | Mandatory Loading Check                              |
| Customer requirement                 | Mandatory Loading Check                              |

## 5. Inspection Procedure

### 5.1 Container Condition

| Check Point                          | Method                                               | Acceptance Criteria              |
|--------------------------------------|------------------------------------------------------|----------------------------------|
| Container number                     | Visual verification vs. booking                      | Matches booking confirmation     |
| Seal number                          | Record                                               | Recorded for documentation       |
| Container exterior condition         | Visual inspection                                    | No damage, rust, holes           |
| Container interior condition         | Visual + olfactory inspection                        | Clean, dry, no odor, no debris   |
| Container floor condition            | Visual inspection                                    | Solid, no holes, dry             |
| Container door operation             | Functional check                                     | Opens/closes properly, seals ok  |

### 5.2 Goods Verification Before Loading

| Check Point                          | Method                                               | Acceptance Criteria              |
|--------------------------------------|------------------------------------------------------|----------------------------------|
| Quantity of cartons / pallets        | Physical count                                       | Match with packing list          |
| Carton condition                     | Visual inspection                                    | No damage, proper sealing        |
| Labeling / shipping marks            | Visual verification                                  | Correct, legible, per spec       |
| Product identity (random check)      | Open 2-3 random cartons                              | Correct product inside           |
| Weight verification (if feasible)    | Weighing                                             | Within declared weight           |

### 5.3 Loading Arrangement

| Check Point                          | Method                                               | Acceptance Criteria              |
|--------------------------------------|------------------------------------------------------|----------------------------------|
| Loading method                       | Visual observation                                   | Proper handling, no throwing     |
| Stacking arrangement                 | Visual inspection                                    | Stable, no crushing risk         |
| Dunnage / bracing                    | Visual inspection                                    | Adequate protection against shifting |
| Weight distribution                  | Visual assessment                                    | Even distribution                |
| Space utilization                    | Visual assessment                                    | Efficient without over-packing   |
| Fragile goods positioning            | Visual verification                                  | On top, properly cushioned       |

### 5.4 Final Verification

| Check Point                          | Method                                               | Acceptance Criteria              |
|--------------------------------------|------------------------------------------------------|----------------------------------|
| All goods loaded                     | Final count vs. packing list                         | 100% loaded                      |
| Container sealed                     | Witness seal application                             | Seal number recorded             |
| Photos taken                         | Camera / phone                                       | Container open, loaded, sealed   |
| Shipping documents complete          | Document review                                      | All documents present and correct |

---

## 6. Decision

| Result          | Action                                               |
|-----------------|------------------------------------------------------|
| **PASS**        | Container sealed. FM-P03-LC signed. Release to Logistics (P04) for shipment. |
| **FAIL**        | Loading stopped. Issues documented. NC opened if applicable. Corrective action before proceeding. |
