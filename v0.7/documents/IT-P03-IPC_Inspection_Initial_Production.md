## 1. Purpose

This work instruction describes the procedure for conducting an **Initial Production Check (IPC)** at the start of production at the supplier's facility. The IPC ensures that raw materials, components, and production parameters conform to the customer's specifications before mass production begins.

---

## 2. Scope

This instruction applies to all orders requiring an IPC inspection as defined in the inspection plan (A1 of process P03).

---

## 3. Trigger Criteria

| Criterion                            | Description                                          |
|--------------------------------------|------------------------------------------------------|
| New supplier (first order)           | Mandatory IPC                                        |
| New product or modified tooling      | Mandatory IPC                                        |
| Supplier with previous NC (Level 2+) | Mandatory IPC                                        |
| Recurring product, Class A supplier  | IPC upon request or if risk identified               |

---

## 4. Preparation

| Step | Action                                   | Responsible   | Documents                     |
|------|------------------------------------------|---------------|-------------------------------|
| 1    | Verify the inspection plan requires IPC  | Quality Role  | Inspection plan               |
| 2    | Obtain customer specifications           | Quality Role  | Technical drawings, specs     |
| 3    | Prepare the IPC checklist                | Quality Role  | FM-P03-IPC template           |
| 4    | Confirm schedule with supplier           | Quality Role  | Email / communication record  |
| 5    | Prepare measurement tools if required    | Quality Role  | Calibration certificates      |

---

## 5. Inspection Procedure

### 5.1 Raw Materials Verification

| Check Point                          | Method                                               | Acceptance Criteria              |
|--------------------------------------|------------------------------------------------------|----------------------------------|
| Material certificates                | Visual review of certificates                        | Match with specifications        |
| Material identification              | Visual check, marking verification                   | Correct grade/reference          |
| Storage conditions                   | Visual inspection                                    | Clean, dry, protected            |
| Incoming quantity                     | Count / weighing                                     | Match with purchase order        |

### 5.2 Components Verification

| Check Point                          | Method                                               | Acceptance Criteria              |
|--------------------------------------|------------------------------------------------------|----------------------------------|
| Component conformity                 | Visual + dimensional check                           | Per drawing tolerances           |
| Component identification             | Label / marking verification                         | Correct reference / batch        |
| Supplier sub-component certificates  | Document review                                      | Valid and complete               |

### 5.3 Production Setup Verification

| Check Point                          | Method                                               | Acceptance Criteria              |
|--------------------------------------|------------------------------------------------------|----------------------------------|
| Tooling condition                    | Visual inspection                                    | Good condition, no wear          |
| Machine settings / parameters        | Review of settings sheet                             | Match with process sheet         |
| First article produced               | Dimensional + visual inspection                      | Within tolerance                 |
| Operator awareness of specifications | Interview                                            | Demonstrates understanding       |
| Work environment                     | Visual inspection                                    | Clean, organized, adequate       |

---

## 6. Decision

| Result          | Action                                               |
|-----------------|------------------------------------------------------|
| **PASS**        | Production may proceed. Record on FM-P03-IPC.        |
| **CONDITIONAL** | Minor deviations noted. Corrective action requested before continuing. Follow-up required. |
| **FAIL**        | Production halted. NC report opened (FM-P03-NC). Supplier must take corrective action. |
