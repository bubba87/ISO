# Planning de Certification ISO 9001:2015 - DUMMY Sarl

## Duree estimee : 9-12 mois

---

## Vue d'ensemble

```
Mois  1-2  : Phase 1 - Preparation et diagnostic
Mois  2-4  : Phase 2 - Construction du SMQ (documentation)
Mois  4-6  : Phase 3 - Mise en oeuvre operationnelle
Mois  6-8  : Phase 4 - Rodage et collecte de preuves
Mois  8-9  : Phase 5 - Audit interne et revue de direction
Mois  9-10 : Phase 6 - Corrections et ameliorations
Mois 10-12 : Phase 7 - Audit de certification
```

| Phase | Duree | Effort estime (heures) |

| Phase 1 - Preparation | 2 mois | 30-50h |
| Phase 2 - Documentation | 2 mois | 60-80h |
| Phase 3 - Mise en oeuvre | 2 mois | 20-30h |
| Phase 4 - Rodage | 2 mois | 10-20h |
| Phase 5 - Audit interne / Revue | 1 mois | 15-20h |
