# Chapitre 4 — Contexte de l'Organisme

## 4.1 Compréhension de l'organisme et de son contexte

### Analyse SWOT de Plus Sàrl

| | Positif | Négatif |
|---|---------|---------|
| **Interne** | **Forces** | **Faiblesses** |
| | Expertise en sourcing et suivi industriel international | Structure légère, dépendance aux partenaires externes |
| | Réseau de fournisseurs qualifiés dans le monde entier | Ressources humaines limitées |
| | Flexibilité et réactivité | Maîtrise indirecte de la production |
| | Connaissance multi-sectorielle | |
| **Externe** | **Opportunités** | **Menaces** |
| | Demande croissante de sourcing international | Instabilité géopolitique dans certaines régions |
| | Digitalisation des processus de suivi | Fluctuations des taux de change |
| | Nouveaux marchés et secteurs industriels | Concurrence accrue sur le sourcing |
| | Exigences qualité croissantes des clients | Perturbations logistiques internationales |

### Enjeux internes

- Maintenir et développer les compétences des rôles clés
- Assurer la continuité des opérations avec une structure légère
- Garantir la traçabilité et la maîtrise documentaire

### Enjeux externes

- Évolution des réglementations dans les pays d'approvisionnement
- Exigences croissantes des clients en matière de qualité et de conformité
- Évolutions technologiques et digitales

## 4.2 Compréhension des besoins et attentes des parties intéressées

| Partie intéressée | Besoins et attentes | Processus concerné |
|-------------------|--------------------|--------------------|
| **Clients** (internationaux) | Produits conformes, délais respectés, prix compétitifs, traçabilité | P01, P03, P04 |
| **Fournisseurs / Partenaires industriels** (internationaux) | Commandes claires, relations durables, paiements dans les délais | P02 |
| **Direction** | Rentabilité, développement, conformité réglementaire | M1 |
| **Collaborateurs** (tous rôles) | Conditions de travail, développement des compétences | M1, S1 |
| **Organismes de certification** | Conformité ISO 9001:2015, amélioration continue | Tous |
| **Autorités réglementaires** | Conformité légale et réglementaire | Tous |
| **Transporteurs / Transitaires** | Informations complètes, planification des expéditions | P03 |

---

*Réf. ISO 9001:2015 — §4.1, §4.2*
