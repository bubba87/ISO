# Field Legend — QMS ISO 9001:2015 Plus Sarl (v0.3)

---

## Marking System

Each field in the QMS documents is identified by a color symbol indicating its status:

| Symbol | Meaning | Description |
|---|---|---|
| 🔴 **[TO BE COMPLETED]** | **Mandatory — information missing** | This field MUST be completed by Roxane Wicky. The information is absent or not disclosed. The auditor will examine it. |
| 🟡 **[RECOMMENDED]** | **Recommended — action to plan** | This field or action is strongly recommended for ISO 9001 compliance, but is not blocking at this stage. |
| 🟢 | **Already filled** | The information is integrated into the document. No action required. |
| 🔵 **[TO BE VERIFIED]** | **To be verified or confirmed** | The information has been pre-filled but must be validated by Roxane Wicky. |

---

## Field Completion Priority

### High Priority (before the certification audit)

- 🔴 All **[TO BE COMPLETED]** red fields
- Fields related to clause 8.4 (suppliers) and 9.2 (internal audit)

### Medium Priority (before the management review)

- 🟡 All **[RECOMMENDED]** yellow fields
- Fields related to customer satisfaction and training

### Low Priority (to be completed as available)

- 🔵 All **[TO BE VERIFIED]** blue fields
- Administrative confirmations, non-blocking clarifications

---

## Usage

1. Browse each document looking for 🔴 🟡 🔵 symbols
2. Start with the 🔴 (mandatory)
3. Replace the marker with the actual information once the field is completed
4. The **INFORMATIONS_MANQUANTES_v0.3.md** document summarizes all fields to be completed
