## 1. Purpose

Define the rules for cause analysis, implementation and verification of the effectiveness of corrective actions in order to eliminate the causes of nonconformities and prevent their recurrence within the QMS of Plus Sarl.

## 2. Scope

Any nonconformity requiring a corrective action:
- Major NCs (systematically)
- Recurrent minor NCs
- Internal or external audit NCs (including SQS certification audit)
- Significant or repetitive customer complaints
- Any situation where the Managing Director deems it necessary to act on the causes

## 3. Definitions

| Term | Definition |
|---|---|
| **Correction** | Action to eliminate a detected NC (immediate symptom treatment) |
| **Corrective action** | Action to eliminate the **cause** of an NC and prevent its recurrence |
| **Root cause** | The fundamental cause at the origin of the NC |
| **Effectiveness verification** | Check that the corrective action has indeed prevented the recurrence of the NC |

> **Key difference:**
> - Correction = "I replaced the defective parts for the customer" (symptom)
> - Corrective action = "I asked the factory to implement strengthened inspection on this reference" (cause)

### 5.2 Step Details

**Step 1 - Open the CA Form**

- Assign a number: AC_[YYYY]_[NNN]
- Link to the originating NC (NC_[YYYY]_[NNNN])
- Describe the problem

**Step 2 - Analyse the Causes**

The cause analysis is carried out by the Managing Director within the scope of her competencies, in coordination with the Chinese partners when the NC is related to manufacturing.

Use the 5 Whys method (recommended for Plus Sarl):

| # | Why? | Answer |
|---|---|---|
| 1 | Why did the NC occur? | [Answer 1] |
| 2 | Why [Answer 1]? | [Answer 2] |
| 3 | Why [Answer 2]? | [Answer 3] |
| 4 | Why [Answer 3]? | [Answer 4] |
| 5 | Why [Answer 4]? | [Answer 5 = probable root cause] |

### 5.3 Typical Corrective Actions for Plus Sarl

The objective of corrective actions is to prevent the recurrence of NCs and reduce the impact on customers. Below are the most common scenarios and associated corrective actions:

#### Scenario 1: Transport Delay

| Element | Detail |
|---|---|
| **Problem** | Delivery delay related to the carrier or freight forwarder |
| **Typical root cause** | Unreliable carrier/freight forwarder, logistics problems |
| **Corrective actions** | - Re-evaluate the carrier/freight forwarder concerned |
| | - Inform the Chinese partners to avoid this provider in the future |
| | - Adapt the logistics choice (change of mode: air/sea/rail) |
| | - Anticipate deadlines in communications to customers |

#### Scenario 2: Production Delay

| Element | Detail |
|---|---|
| **Problem** | Manufacturing delay at the Chinese partner |
| **Typical root cause** | Insufficient planning, factory overload, technical problem |
| **Corrective actions** | - Strengthened monitoring with the Chinese partners (more frequent progress updates) |
| | - Push for better deadlines and improved planning |
| | - Anticipate communications to customers in case of delay risk |
| | - Commercial adjustments if necessary (goodwill gesture, staggering) |

#### Scenario 3: Production Defect

| Element | Detail |
|---|---|
| **Problem** | Parts not conforming to specifications (dimensions, appearance, material) |
| **Typical root cause** | Machine setting problem, mould wear, material error, insufficient inspection |
| **Corrective actions** | - Ask the factory to retain the NC information |
| | - Request the implementation of strengthened inspections on future production runs of this reference |
| | - Replacement of nonconforming parts for the customer |
| | - Logistics adaptation if necessary (urgent re-shipment) |
| | - Strengthened partner monitoring (continuous quality monitoring) |
| | - Strengthen pre-shipment QC and sampling (cf. PRO-ACH-001, section 8) |
| | - Commercial adjustments if necessary |

#### Scenario 4: Labelling or Packaging Error

| Element | Detail |
|---|---|
| **Problem** | Labelling or packaging error (incorrect reference on the label, mix-up between similar references) |
| **Typical root cause** | Mix-up between similar references, absence of inspection checklist, insufficient verification before shipment |
| **Corrective actions** | - Create a comprehensive quality control checklist covering labelling and packaging |
| | - Strengthen label verification before shipment |
| | - Clarify references with the supplier (particularly similar references that could cause confusion) |
| | - Ask the supplier to implement a double-check on labelling |
| | - Integrate labelling control into pre-shipment QC |

> **Guiding principle:** The corrective actions of Plus Sarl aim to prevent recurrence and reduce the impact on the customer. The Managing Director acts within the scope of her competencies and relies on her Chinese partners (Yuyao Mould Factory and Whang) for the technical aspects of manufacturing.

**Step 3 - Identify the Root Cause**

- Select the most probable cause
- Verify with data/evidence if possible (photos, reports, email/WeChat exchanges)

**Step 4 - Define the Corrective Action**

The corrective action must:
- Act on the root cause (not on the symptom)
- Be realistic and proportionate to the means of Plus Sarl
- Have a responsible person and a deadline
- Be communicated to the relevant Chinese partner if necessary

**Step 5 - Implement**

- Carry out the action or coordinate its implementation by the Chinese partner
- Document what has been done
- Communicate the actions to the parties concerned (Chinese partner, customer, carrier)

**Step 6 - Verify Effectiveness**

- Allow a sufficient period (generally 1 to 3 months or the next orders of the same type)
- Verify that the NC has not recurred during subsequent production runs/deliveries
- If the NC recurs: resume the cause analysis, consider stronger measures

> **Completion instructions:**
> 1. Only open a CA if it is justified (major NC, recurrent, or audit finding)
> 2. Take the time to properly analyse the root cause -- this is the key step
> 3. The 5 Whys method is simple and effective for a micro-enterprise such as Plus Sarl
> 4. Involve the Chinese partners (Yuyao Mould Factory or Whang) in the analysis when the NC originates from manufacturing
> 5. Document exchanges (emails, WeChat) as evidence of corrective actions
> 6. The auditor (SQS) will verify that your CAs are effective (not just on paper)
> 7. The cause analysis is carried out within the scope of the Managing Director's competencies -- it is a continual improvement approach
> 8. Pre-shipment QC with sampling can be a source of CAs if NCs are detected before delivery
